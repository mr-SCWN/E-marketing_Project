# UE Battle Prototype

**UE Battle Prototype** to statyczna strona internetowa przygotowana jako projekt z przedmiotu e-marketing. Strona promuje grywalny prototyp gry akcji stworzony w Unreal Engine 5.6.

Projekt gry przedstawia trzecioosobowy prototyp walki arenowej. Gracz wciela się w rycerza wyposażonego w miecz i tarczę, wchodzi na areny, walczy z falami przeciwników, wybiera nagrody po oczyszczeniu lokacji i przechodzi dalej.

Strona internetowa została zaprojektowana jako marketingowy landing page z dodatkowymi podstronami. Jej celem jest zachęcenie użytkownika do pobrania prototypu, zapisania się do testów oraz zostawienia opinii o projekcie.

Na stronie wykorzystano elementy e-marketingu, takie jak:
- główne wezwanie do działania: „Pobierz prototyp”,
- formularz zapisu do testów,
- formularz opinii,
- sekcja galerii z materiałami z gry,
- sekcja FAQ,
- przykładowe opinie użytkowników,
- dodatkowy landing kampanii „Beta Weekend”,
- linki do społeczności i udostępniania.

Strona została wykonana w technologii HTML, CSS i JavaScript. Projekt jest responsywny i może działać lokalnie lub jako strona opublikowana przez GitHub Pages.
